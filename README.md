CarneClick – Sistema de Gestión Cárnica

CarneClick es un sistema web desarrollado en Django para la gestión de productos cárnicos, clientes y ventas, pensado para carnicerías, comercios minoristas y pequeños negocios del rubro alimenticio.

El objetivo principal del sistema es simplificar el control del negocio, permitiendo administrar productos, precios y operaciones desde un navegador web de forma sencilla e intuitiva.

¿Qué es CarneClick?

CarneClick es una aplicación web que permite:

Gestionar productos cárnicos

Administrar clientes

Controlar operaciones básicas del negocio

Acceder al sistema desde cualquier navegador

Centralizar la información del comercio

Está pensada para ser simple, clara y fácil de usar, incluso para personas sin conocimientos técnicos.

Tecnologías utilizadas

Python 3

Django

SQLite (base de datos)

HTML + Bootstrap

JavaScript

CSS

Requisitos técnicos

Antes de comenzar, asegurate de tener:

Una computadora con Windows, Linux o macOS

Conexión a internet

Un navegador web (Chrome, Edge, Firefox, etc.)

No hace falta tener experiencia previa en programación.

Instalación completa (explicada paso a paso)
